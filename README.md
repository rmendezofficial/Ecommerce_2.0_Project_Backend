# Ecommerce_2.0_Project_Backend
This is the backend of a full ecommerce project. It was implemented using fastAPI and a mySQL database. It is a monolithic system, since it is intended to be a personal project, so it will not have a significant traffic to require a more complex architecture. At the moment, the project is not completed, and the backend only contains the users system. The users can sign up, log in, see their profile, and log out. The system uses a cookie-based JWT-based authentication system with bcrypt password hashing and role-based access control (RBAC). When the users log in, an access token and a refresh token are generated and stored in cookies in the user's browser. Then, when the users try to access a protected route, the cookie is accessed to check if the access token is valid. If the access token is not valid but the refresh token is still valid, the user receives a new access token; this way, the users can remain authenticated without having to use their password constantly to log in. Currently, there are three roles: Admins, employees, and customers. The backend has not been tested with unit tests or integration tests, but only by me acting as a user and testing the overall behavior. Moreover, it does not have rate limiting nor other security measures yet. Also, the project has documentation, error handling with custom errors and input validation. Nonetheless, it probably has some errors regarding the connection to the database or the lack of usage of transactions, since I do not know much about them and I did not take into account consistency nor isolation levels when building the project.

The "commands.txt" file contains the scripts that I used to download libraries and build the project.
